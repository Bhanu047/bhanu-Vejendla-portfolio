STREAMING DATA PLATFORM

Weblog Stream

PROBLEM

Web events can arrive late, duplicated or malformed. This project shows how I keep a real-time pipeline useful when the input is imperfect and the job has to recover from interruption.

ENGINEERING DECISION

I separated invalid events into a dead-letter path, used event-time watermarks for bounded state and checkpointed the stream. The Parquet writer keeps replayed micro-batches safe without erasing earlier batches.
